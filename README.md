# QatanCraft

**QatanCraft** لعبة voxel ثلاثية الأبعاد للجوال من **Abdullah Qatan**، مبنية على Godot 4.7.2 وبمكونات مفتوحة الرخصة.

## ما تم تنفيذه

- عالم مكعبات مولّد برمجيًا مع تضاريس وأشجار ورمال.
- استكشاف بمنظور ثلاثي الأبعاد، جمع الموارد، تكسير المكعبات وبناء المكعبات.
- واجهة لمس كبيرة للهاتف: أسهم حركة، كسر، بناء، وتبديل المادة.
- شاشة بداية تحمل اسم **Abdullah Qatan**.
- حفظ تلقائي محلي للعالم في `user://qatancraft_world.json`.
- مؤثرات صوتية أصلية خفيفة للواجهة والكسر والبناء.
- إعداد تصدير Android ضمن `export_presets.cfg`، مع إبقاء تصدير Web للمعاينة فقط.

## التشغيل والتصدير

يتطلب Godot 4.7.2. افتح المشروع ثم اختر المشهد `scenes/main.tscn`.

```bash
npm run check
npm run build
```

لتصدير تطبيق Android بعد تثبيت Android SDK وExport Templates:

```bash
godot --path . --export-release Android dist/QatanCraft.apk
```

> نسخة Web الموجودة في المشروع مخصصة للمعاينة الآلية فقط؛ هدف اللعبة الأساسي هو Android والهاتف.

## الرخص

كود اللعبة من هذا المستودع متاح تحت MIT. Godot وموارده المفتوحة تحت رخصها الأصلية. المؤثرات الصوتية الموجودة في `audio/` مولّدة خصيصًا لهذا المشروع ويمكن إعادة استخدامها وتعديلها.
